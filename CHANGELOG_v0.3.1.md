# REELMAKER 0.3.1 — preparación de distribución

- Configuración de rutas compatible con PyInstaller y datos por usuario en Windows.
- FFmpeg/FFprobe incluidos en `ffmpeg/bin` dentro de la distribución.
- Escapado de rutas de subtítulos compatible con rutas Windows.
- Corregidos saltos de línea SRT y mensaje de finalización.
- Eliminada la opción engañosa de conservar originales: esta versión nunca borra el vídeo fuente.
- Añadidos tests automáticos de base de datos, candidatos y utilidades de vídeo.
- Añadidos scripts de build y documentación para Windows.
